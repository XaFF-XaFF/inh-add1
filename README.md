# Pokemon Battle Simulator

I chose the Pokemon battle simulator for this assignment. The app lets the user choose two Pokemon and battle using live data from PokeAPI. Both Pokemon fight at level 50. The user chooses a move each turn, while the opponent chooses randomly. Completed battles are saved in a local history, and the result can be shared.

The additional features are:

- **Custom movesets:** the user can choose up to four moves before the battle. The available moves are based on the selected Pokemon species and its learnable moves from PokeAPI.
- **Simple battle animations:** Pokemon move when attacking, react to damage, and fade when they faint. HP bars decrease gradually, and attacks play one at a time so the fight and its result are easier to follow.
